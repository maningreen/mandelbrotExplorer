# mandelbrotExplorer

this is a little project of mine to explore fractals!

here are the controls:
  - wasd to move the camera
  - q & e to zoom in / out
  - arrow keys to change the offset

## Build

In order to build, one needs the following
  - Raylib 5.5
  - Gnumake
  - Gcc

then, build with
```
$ make
```
and run with 
```
$ ./mandel
```
